# MarsCloud SaaS

MarsCloud SaaS 是 Mars Semiconductor Corp. 所提供的原生雲端與微服務整合平台。

此公開 Repository 目前提供產品介紹、系統架構與 API 使用文件，方便開發者了解 MarsCloud 的設計理念與服務整合方式。

## 公開內容

- `Doc/01. 原生雲設計理念.md`：原生雲設計思維與核心概念。
- `Doc/02. 原生雲設計架構.md`：微服務、REST API、MQTT 與混合雲架構。
- `Doc/03. APIs 快速使用說明.md`：MarsCloud REST API 使用方式。
- `Doc/04. 進階撰寫技巧.md`：資料識別、二進位資料與批次存取建議。

## SDK 與範例

SDK 與微服務範例目前正在進行封裝與公開介面整理，尚未於此 Repository 發布。完成安全審查與封裝後，將以獨立版本提供安裝與使用說明。

目前既有的 SaaS 核心服務、內部工具與未封裝 SDK 原始碼皆維持於私人 Repository，不包含在本公開 Repository 中。
